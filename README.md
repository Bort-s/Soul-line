# Soul Line
From the void, reach the light.

## Description
Soul Line is a simple 2D platformer Godot game where you have to walk around ancient platforms to reach the light.

You can download it [here](https://github.com/Bort-s/Soul-line/releases/download/v1.0/soul_line.zip) (Windows only) 

or [play it in your browser](https://bort2441.itch.io/soul-line) on itch.io
## How to play
1. Download the game build ZIP from Releases
2. Unzip it
3. Search and open the .exe file
4. Allow the game to open to any external program, like an antivirus (for **Windows SmartScreen**, click "*More info*" and "*Run anyway*").

## Controls
- A/D to go to the left and right
- Space bar to jump
